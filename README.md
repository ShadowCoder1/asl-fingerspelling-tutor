# ASL fingerspelling tutor (research prototype)

Live: https://shadowcoder1.github.io/asl-fingerspelling-tutor/

A webcam tutor for ASL fingerspelling handshapes: it shows a letter, you sign
it, and it says whether the handshape is right and which part of the hand to
fix. Hand tracking is Google's MediaPipe; the grader is a small statistical
model fitted on public, openly licensed hand-landmark datasets (attributions
are inside `tutor/model.json`). Everything runs in the browser. No video or
landmarks leave the page.

This teaches fingerspelling handshapes, not ASL. To learn ASL, learn from Deaf
teachers. Grading is approximate and can be wrong.

This folder is a published copy of the running site only; it is generated by
`tools/publish-site.sh` in the working repository.
